# ComfyAI

## Summary

ComfyAI is an AI-powered comfort companion designed to provide supportive, empathetic, and non-judgmental conversations. It aims to help users express their feelings and receive comforting responses through a friendly conversational interface.

The project uses Flutter Web and Dart for its user interface. Future development may include AI integration, backend communication through a REST API, and PostgreSQL for persistent data storage, depending on the approved system design.

## Current Technology Stack

- **Dart** – Programming language
- **Flutter Web** – Client-side user interface and application development
- **REST API** – Planned backend communication
- **PostgreSQL** – Planned relational database

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ashleyjoydpullos-cloud/comfyAI.git
   ```

2. Enter the project directory:

   ```bash
   cd semester_project
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run -d chrome
   ```
